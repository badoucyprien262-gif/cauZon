# Backend Node.js cauZon (DÉPRÉCIÉ / RETIRÉ)

> ⚠️ **OBSOLÈTE : Ce serveur backend Node.js local n'est plus requis.**
> 
> Conformément à l'architecture Supabase Serverless & PWA de cauZon :
> - La compression des PDF est exécutée directement côté client via `pdf-lib`.
> - Le téléversement est envoyé directement vers le stockage Cloud Supabase (`cours-documents`).
> - La synchronisation de la table `documents` s'effectue directement via le SDK `@supabase/supabase-js`.
> 
> Aucun terminal ni écoute sur le port `http://localhost:3001` n'est désormais nécessaire pour faire fonctionner le dashboard d'administration `administrateur_cauZon`.
